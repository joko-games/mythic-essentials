# CurseForge page

The texts of the project page on CurseForge, kept here so that they follow the addon. When a feature worth showing is added, changed or removed, update them here, then paste them into the project settings on CurseForge. The description uses CurseForge's Markdown editor.

## Icon

The project icon is `art/icon.png` (512 x 512), the same drawing as the icon in the game and on the minimap (CC0, docs/development.md).

## Summary

The catchline shown under the name in search results and lists:

> A tiny Mythic+ window: group DPS in class colours, the key timer and progress, and who forgot their flask or food.

## Description

```markdown
# Mythic Essentials

What a Mythic+ run needs at a glance, in one small window.

- **Group DPS**: five bars in class colours, with no names to clutter them. Hover a bar to see who it is, their DPS and their damage. The numbers come from the game's own damage meter, so they keep working under Midnight's combat restrictions.
- **Key timer and progress**: the time left for the next chest (+3, +2, +1), a timer bar with the chest marks, enemy forces in percent, deaths and the time they cost, and each boss with the time it died.
- **Consumables**: "No flask: 2", "No food: 1". Hover the number to see who. When everyone is ready, nothing is shown.

Drag the window where you want it. The minimap icon shows or hides it (left click) and locks it in place (right click).

Commands: `/mye` shows or hides the window, `/mye lock`, `/mye scale 0.8`, `/mye reset`, `/mye minimap`, and `/mye demo` to place the window outside a dungeon.

The third of the Essentials, after Trading Essentials and World Quest Essentials. In English and French.
```
